# Doctor Speech — Data Source Specification

## Purpose
Define a separate source category for doctor/clinician speech if the approved study includes professional voice users.

## Required metadata
- Coded speaker ID
- Professional role
- Age/sex only when approved and necessary
- Task
- Sustained /a/ where required by protocol
- Reading/conversation task where included
- Recording device
- Microphone distance and angle
- Sampling rate
- Channels/bit depth
- Room/environment
- Consent/permission
- Date/session
- File hash
- PhonaCore/DSP build

## Measurements
Apply the same measurement registry:
F0, Fhi, Flo, STD, T0, Jita, Jitt, RAP, PPQ, sPPQ, vF0, ShdB, Shim, APQ, sAPQ, vAm, NHR, VTI, SPI, DVB, DSH, DUV, NUV, NVB, NSH, SEG, PER, PFR, FTRI, ATRI, Fftr, Fatr and Tsam.

## Research boundary
Doctor/clinician occupation is not a diagnostic label. Do not classify a doctor's voice as normal merely because of occupation. Do not use recordings without permission/consent.
