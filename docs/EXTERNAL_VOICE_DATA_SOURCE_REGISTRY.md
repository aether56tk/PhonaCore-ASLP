# External Voice Data Source Registry

This is the master source registry for all external speech/voice material.

## Required fields
- Source/dataset name
- Version
- Creator/organization
- Publication/citation
- URL
- License/permission
- Speaker count
- Demographics
- Voice task
- Recording conditions
- Sampling rate
- File format
- Labels/ground truth
- Intended analysis
- Inclusion/exclusion criteria
- Import date
- Hash/version

## Planned source categories
- MDVP reference
- Doctor/clinician speech
- Varghee — exact source to be verified
- Prachi — exact source/version/license to be verified
- MDDB — exact source/version/license to be verified
- Other approved external voice datasets

No source is considered part of the research dataset until its provenance and permitted use are documented.
