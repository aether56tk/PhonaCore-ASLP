# PhonaCore Validation Status

## Software status

The measurement, research, reporting, security, reproducibility and validation **software workflows are implemented** and covered by automated tests.

## Remaining work

**Empirical validation is the only remaining research milestone.**

It must use an appropriately governed reference dataset and frozen software/protocol. Results should report measurement-specific agreement/error, failure cases and limitations.

Synthetic benchmarks and automated tests are software verification only. They must not be presented as evidence of clinical validity.

## Data governance

No identifiable participant data, consent documents or clinical recordings belong in this public repository.
