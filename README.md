# PhonaCore-ASLP

Browser-based acoustic voice analysis, clinical assessment and research validation platform for Audiology & Speech-Language Pathology.

## Run
```bash
npm install
npm test
npm start
```

Open http://localhost:5173.

## Boundary
This is a research/educational engineering prototype. Acoustic algorithms require independent validation against a defined reference implementation and representative data before clinical interpretation or publication claims. No diagnostic or regulatory claims are made by the software alone.
