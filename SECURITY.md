# Security Policy

PhonaCore-ASLP processes potentially sensitive voice data. Never commit identifiable participant recordings, consent documents, clinical records, credentials, or private datasets.

Do not publish sensitive vulnerability details or private data in public issues. Contact the maintainer privately through the GitHub profile.

Relevant reports include unsafe audio/file handling, XSS or unsafe browser processing, privacy/data-retention problems, server-side security issues, dependency/CI vulnerabilities, and unintended exposure of analysis data.
